# Sword-of-Blossoming-Dawn-Calculator
shitty WIP python script to calculate BiS items to build for sword of blossoming dawn in aram mayhem

Current Features (v1.3.1)
 - Large augment selection list
 - Shows 'optimal' full build + path
 - Dynamic augment and item options
 - Bonus stat inputting

Notes
 - Builds are calculated using level 18 stats averaged across all champions
 - Runaans assumes you are hitting 3 targets
 - Helia assumes you are hitting only 1 champion
 - Helia values are typically lower on champions with low base stats and low damage baked into their kit and vise versa
 - I still need more information on how many augments affect stats and am playing games to try and hit certain augments for testing
 - Still uses items names I used for testing purposes, will update later, but its not a current priority
 - Most item/augment passives are considered to have full uptime (critical rythm/rageblade stacks for example)
 - Building more AD causes you to heal more off of enemies while AP heals more from waves (due to how helia works and AD clearing waves faster)
